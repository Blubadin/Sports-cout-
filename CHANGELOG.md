# Changelog

## 0.11.0-pilot.1

- Established the Coach Pilot baseline on merge commit `03d5c1c`.
- Kept export/import schema at `1.1` and added optional app-version metadata.
- Kept the existing Classic interface as the default; Workstation remains behind a disabled feature flag.
- Added pilot hardware, workflow, viewport, endurance, and coach-session evidence gates.
- Added offline Noto Sans and Noto Sans Thai typography, restored native Tab navigation, and scoped view switching to Ctrl+Tab.
- Added a shared sport geometry contract for Normal Input, Pro HUD, Field Map, Table, CSV, and reports.
- Added Auto, Full Court, and Half Court area views with canonical 0-1 coordinates and 5% out-of-bounds lanes.
- Added 4x6 football detail, 3x3-per-side badminton detail, and shot-12 basketball detail while preserving schema `1.1` compatibility.
