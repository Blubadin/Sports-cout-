## งานที่ให้ทำ

- เปิดโปรเจกต์และวิดีโอ
- สร้าง event แรก
- บันทึกอย่างน้อย 20 events
- แก้ไข ลบ Undo/Redo และ Bookmark
- เปิด Dashboard/Table/Field Map
- Export และเปิดโปรเจกต์กลับมา
- สำหรับจอย: เปิด History, Replay, Key Moments และกลับ HUD โดยไม่ใช้เมาส์

## ปัญหาที่พบ

บันทึกเวลา ขั้นตอน ผลที่คาดหวัง ผลจริง และความรุนแรง ห้ามใส่ชื่อผู้ใช้หรือข้อมูลในวิดีโอ

## คำถามหลังจบ

1. จุดใดทำให้ลังเลมากที่สุด?
2. ข้อมูลใดที่โค้ชต้องการแต่หาไม่พบ?
3. ปุ่มหรือคำใดเข้าใจยาก?
4. งานใดต้องกลับไปใช้เมาส์?
5. สิ่งใดต้องแก้ก่อนใช้ในชั้นเรียนหรือทีมจริง?
