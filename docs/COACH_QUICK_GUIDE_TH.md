# SPORTSCOUT: คู่มือเริ่มต้นสำหรับโค้ช

คู่มือนี้ใช้กับ SPORTSCOUT Pilot `0.11.0-pilot.1` และ export schema `1.1`

## เริ่มใช้งานใน 4 ขั้นตอน

1. **สร้างโปรเจกต์** เลือก Volleyball, Football, Badminton หรือ Basketball แล้วตั้งชื่อการแข่งขันและทีม
2. **เปิดวิดีโอ** เลือกไฟล์ในเครื่องหรือใส่ลิงก์ YouTube ตรวจว่าปุ่ม Play, Pause และ Seek ทำงานก่อนเริ่มบันทึก
3. **บันทึกเหตุการณ์** เลือกทีม ทักษะ พื้นที่ และผลลัพธ์ แล้วกดบันทึก สามารถใช้ Normal Input, Pro HUD หรือ Controller V1
4. **ตรวจและส่งออก** ตรวจ Events Table, Dashboard, Field Intelligence และ Data Quality ก่อนส่งออก JSON หรือ CSV

## ก่อนเริ่มแมตช์

- ตรวจชื่อทีม ฝั่งสนาม ชนิดกีฬา และรูปแบบเซต
- ทดลองบันทึกหนึ่งเหตุการณ์แล้ว Undo เพื่อยืนยัน workflow
- ถ้าใช้จอย ให้เปิด `ตั้งค่า > ตั้งค่าจอย` แล้วทดสอบ Mapping และแกนจอย
- ถ้าใช้วิดีโอ local ให้เก็บไฟล์ต้นฉบับไว้ตำแหน่งเดิม ระบบไม่อัปโหลดหรือฝังไฟล์วิดีโอในโปรเจกต์

## ระหว่าง Scouting

- อย่าเปลี่ยนชนิดกีฬาหลังมีเหตุการณ์แล้ว
- ตรวจสถานะบันทึกด้านบนให้เป็น `บันทึกแล้ว / Saved`
- ถ้า PWA แจ้งว่ามีเวอร์ชันใหม่ ให้บันทึกหรือล้าง action ที่กำลังเลือกก่อนกดอัปเดต
- ใช้ Bookmark สำหรับช่วงสำคัญที่ต้องการเปิดดูซ้ำ

## หลังจบงาน

- ตรวจจำนวน Events, Actions และ Derived Outcome Points ว่าเป็นคนละความหมาย
- เปิด Data Quality และแก้รายการ incomplete หรือ invalid ก่อนนำสถิติไปใช้
- ส่งออก JSON เป็นไฟล์สำรองหลัก และ CSV สำหรับ Excel/Google Sheets
- เก็บชื่อไฟล์วิดีโอคู่กับไฟล์ JSON เพราะ SPORTSCOUT ไม่เก็บ raw video ใน export

## เมื่อต้องขอความช่วยเหลือ

ไปที่ `ตั้งค่า > ข้อมูล` แล้วกด **ส่งออกข้อมูลวินิจฉัย Pilot** รายงานนี้มีเฉพาะเวอร์ชัน จำนวนข้อมูล สถานะบันทึก และพื้นที่จัดเก็บ ไม่รวมชื่อทีม โน้ต เนื้อหา scouting วิดีโอ หรือข้อมูลระบุตัวจอย
